# Privacy Policy – Bliss 快速填單

Last updated: 2026-10-28

Bliss 快速填單 is an internal productivity tool for customer support agents. It does not sell data, does not use data for advertising, and does not share data with third parties.

## Data handling

- Values entered in the extension's side panel (such as email, CC, subject and message) are used only to fill a form on a customer support web application in the user's own browser session.
- When the user enters an email address, the extension sends that email address to a Google Apps Script web app owned and operated by the user's own organization, in order to retrieve the matching reply template (CC, subject and message) from the organization's Google Sheet. Access to that web app is restricted to authenticated members of the organization.
- The extension does not collect or transmit browsing history, and does not read any web page other than the customer support web application it is designed to work with.
- The developer does not operate any external server and does not receive any of this data.

## Permissions

The extension requests access only to the customer support web application and to script.google.com / script.googleusercontent.com, solely for the purposes described above.
